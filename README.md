# lukehjohnson.com

Static author and columnist website for Luke Johnson, served by GitHub Pages
at https://lukehjohnson.com (see `CNAME`).

## Pages

- `index.html` — front page: latest column, more columns, Dead Air America, outlets, books
- `writing.html` — every column and feature (searchable), plus the outlet directory by state
- `books.html` — Dead Air America and the published books
- `about.html` — bio and FAQ
- `contact.html` — contact form
- `404.html` — not-found page

## Content

Columns and outlets are managed at **https://lukehjohnson.com/admin.html**.
Sign in, then add, edit, or delete columns (with an optional cover photo) and
outlets. Changes show on the live site right away; the hourly GitHub Action
(`.github/workflows/refresh.yml`) rebuilds the HTML so search engines see them
within the hour. To refresh sooner: Actions > Refresh pages > Run workflow.

How it works:

- The data lives in a Supabase project (see `assets/js/supabaseConfig.js`).
  `supabase/setup.sql` creates the tables, the storage bucket for cover
  photos, and the security rules: anyone can read, only accounts listed in
  `public.admins` can change anything. Passwords are handled by Supabase Auth
  and never appear in this code.
- The browser loads columns and outlets from Supabase (`assets/js/main.js`);
  if that fails, visitors see the last build.
- `node scripts/build.js` writes the columns, books, and outlet lists into the
  HTML (between `<!-- build:... -->` markers), updates counts, regenerates the
  JSON-LD structured data and `llms.txt`. It reads Supabase when configured and
  `assets/js/archiveData.js` otherwise; `--offline` forces the file.
- Books still live in `assets/js/archiveData.js`. After editing them, run
  `node scripts/build.js` (or let the Action do it on push).

### First-time Supabase setup

1. Supabase > SQL Editor: paste `supabase/setup.sql` and run it.
2. Authentication > Sign In / Providers: turn off "Allow new users to sign up".
3. Authentication > URL Configuration: set Site URL to
   `https://lukehjohnson.com/admin.html`.
4. Authentication > Users > Add user > Send invitation, to your email. The
   email's link opens the admin page, where you choose your password.
5. SQL Editor: run the "Make yourself an admin" statement at the end of
   `supabase/setup.sql` with your email.
6. Sign in at `/admin.html` and click "Import current site data" once.

## SEO and AI search

- The name is "Luke H. Johnson" everywhere. Structured data uses one Person,
  `https://lukehjohnson.com/#person`, with `alternateName` and a
  `disambiguatingDescription` separating him from the British businessman
  Luke Johnson. Official profiles go in `person.sameAs` in `scripts/build.js`.
- `robots.txt` allows all crawlers, including AI search and training bots, and
  points to `sitemap.xml`. Update the sitemap's `lastmod` dates when pages change.
- `llms.txt` is a plain-text summary for AI assistants, generated by the build.
- `archive.html` and `publications.html` redirect old links to `writing.html`.

## Contact Form Google Sheets Setup

The contact form is wired to send submissions to a Google Apps Script Web App. The form posts these columns:

- Timestamp
- Name
- Email
- Subject
- Message
- Source Page
- Inquiry Type

### 1. Create the Google Apps Script

1. Go to [script.google.com](https://script.google.com/).
2. Create a new project.
3. Replace the default code with the contents of `google-apps-script.js`.
4. Save the project.

The script will create or reuse a Google Sheet named `Luke Johnson Website Contacts`.

### 2. Deploy the Web App

1. Click **Deploy**.
2. Choose **New deployment**.
3. Select **Web app**.
4. Set **Execute as** to **Me**.
5. Set **Who has access** to **Anyone**.
6. Deploy and authorize the script.
7. Copy the Web App URL ending in `/exec`.

### 3. Connect the Website

Open `assets/js/contactConfig.js` and paste the Web App URL:

```js
window.contactFormConfig = {
  googleAppsScriptUrl: "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec"
};
```

### 4. Test

Open `contact.html`, submit a test message, then confirm a new row appears in `Luke Johnson Website Contacts`.

Success message:

> Thank you for reaching out. Your message has been received and I will respond as soon as possible.

Error message:

> There was a problem submitting your message. Please try again later.
